# Project Template

Tạo bản sao bộ mẫu này cho từng Project ID sau khi được phân công. Repo/nhánh riêng; không trộn credentials, dữ liệu hoặc môi trường dự án.

**Bắt buộc ghi rõ:** mục tiêu, chủ sở hữu, repository mới được chỉ định, môi trường, stack, current gate, task/evidence và tình trạng phê duyệt.
