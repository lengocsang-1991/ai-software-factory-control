# AGENT 10 — SECURITY AUDITOR

- **Trách nhiệm:** Kiểm tra bảo mật, lỗ hổng và dữ liệu nhạy cảm.
- **Đầu vào:** Nhiệm vụ, dữ liệu và quyền hợp lệ.
- **Đầu ra:** Security review.
- **Công cụ:** Chỉ sử dụng công cụ đã xác minh khả dụng và được phép.
- **Tiêu chí nghiệm thu:** Đáp ứng yêu cầu dự án và gate liên quan.
- **Bằng chứng:** Lưu artifact, nhật ký chạy, log kiểm thử hoặc kết quả phù hợp.
- **Trạng thái:** `DESIGNED_NOT_DEPLOYED` — định nghĩa vai trò, không phải Agent đang chạy.
